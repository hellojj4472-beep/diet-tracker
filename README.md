# 다이어트표

하루 식사·운동·수면·배변을 한 화면에서 기록하는 개인용 다이어트 트래커입니다.

## 지금 상태 (Phase 1)

- `index.html` 하나로 동작하는 정적 웹앱입니다. 별도 설치나 빌드 과정이 없습니다.
- 데이터는 브라우저의 `localStorage`에 날짜별로 저장됩니다 (오늘 입력한 내용은 새로고침해도 유지되지만, 다른 브라우저/기기에서는 보이지 않습니다).
- 음식 검색은 42종의 샘플 데이터로 동작하는 목업입니다 (실제 식품 API 아님).
- 생활습관 추천은 규칙 기반(if-then 조건표)으로 동작하며, 외부 API를 호출하지 않습니다.

## 로컬에서 열어보기

`index.html` 파일을 브라우저로 더블클릭해서 열면 바로 사용할 수 있습니다.

## 로드맵

- **Phase 2 — Google Sheets 연동**: Google Apps Script를 웹앱으로 배포해서, 이 페이지가 그 주소로 fetch 요청을 보내면 내 구글시트에 기록이 쌓이도록 연결합니다. 서비스 계정 키를 클라이언트 코드에 넣지 않는 방식이라 안전합니다.
- **Phase 3 — 외부 식품 DB 연동**: 공공데이터포털 식품영양성분DB API를 우선 사용하고, 실패 시 Open Food Facts로 폴백합니다.

자세한 기획 배경은 상위 폴더의 `다이어트표_기획서.md`를 참고하세요.

## 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다 (Public, README 없이).
2. 이 폴더를 그 저장소에 push 합니다.
3. 저장소 Settings → Pages → Source를 "Deploy from a branch"로, Branch를 `main` / `/(root)`로 설정합니다.
4. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 폰에서도 동일하게 사용할 수 있습니다.
