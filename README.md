# 일정관리 (구 다이어트표)

하루 식사·운동·수면·배변을 한 화면에서 기록하는 개인용 다이어트 트래커입니다.

## 지금 상태 (Phase 2까지 완료)

- `index.html` 하나로 동작하는 정적 웹앱입니다. 별도 설치나 빌드 과정이 없습니다.
- 데이터는 브라우저의 `localStorage`에 날짜별로 자동 저장됩니다.
- 상단 "☁️ 구글시트에 저장" 버튼을 누르면 `apps-script/Code.gs`를 배포한 Google Apps Script 웹앱으로 오늘 기록을 백업합니다. 추이 그래프는 시트에 2일 치 이상 기록이 쌓이면 실제 데이터로 자동 전환됩니다.
- 음식 검색은 64종의 샘플 데이터로 동작하는 목업입니다 (실제 식품 API 아님).
- 생활습관 추천은 규칙 기반(if-then 조건표)으로 동작하며, 외부 API를 호출하지 않습니다.

**보안 참고**: `index.html`에 Apps Script 웹앱 주소와 토큰이 그대로 들어있습니다. 이 저장소가 Public이라 코드를 보면 누구나 알 수 있는 값이지만, 이 토큰으로 할 수 있는 건 이 시트 한 장에 쓰고 읽는 것뿐이라 실제 위험은 낮습니다. 걱정되면 Apps Script 편집기에서 `TOKEN` 값을 바꾸고 새 버전으로 재배포한 뒤, 이 파일의 `SHEETS_TOKEN`도 같이 바꿔주세요.

## 로컬에서 열어보기

`index.html` 파일을 브라우저로 더블클릭해서 열면 바로 사용할 수 있습니다.

## 로드맵

- ~~Phase 2 — Google Sheets 연동~~ 완료. `apps-script/Code.gs`가 Apps Script 웹앱으로 배포되어 있고, 페이지의 저장 버튼이 그 주소로 fetch 요청을 보냅니다.
- **Phase 3 — 외부 식품 DB 연동**: 공공데이터포털 식품영양성분DB API를 우선 사용하고, 실패 시 Open Food Facts로 폴백합니다.
- **기기 간 동기화**: 오늘의 기록(식사/운동/수면/배변/체중), 일정, 근무표는 구글시트를 통해 다른 기기에서도 보입니다. 단, 생리주기·사랑♥ 표시·반복일정관리는 개인정보 보호를 위해 각 기기(브라우저)에만 저장되고 구글시트로는 전송되지 않습니다.

자세한 기획 배경은 상위 폴더의 `다이어트표_기획서.md`를 참고하세요.

## 배포 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다 (Public, README 없이).
2. 이 폴더를 그 저장소에 push 합니다.
3. 저장소 Settings → Pages → Source를 "Deploy from a branch"로, Branch를 `main` / `/(root)`로 설정합니다.
4. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 폰에서도 동일하게 사용할 수 있습니다.
